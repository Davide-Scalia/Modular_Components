# RPG Toolkit: first 2D Top Down slice

Open **Window > RPG Toolkit > Setup** to choose a saved preset, edit a draft, save it, and create a new character prefab. The prefab contains its own movement settings. For grid exploration, place the prefab in a scene with a `GameplayGrid2D` Tilemap and assign it through `GameplayGridBinder`. The grid uses a `TopDownTileRules` asset for walkability, entry cost, and cardinal edge rules. Actors occupy cells independently of the existing road placement grid.

Create map nodes as scene GameObjects with `MapNode` and `NodeMapNodeView` components. Connect their outgoing links by dragging other scene nodes into each `MapNode` list. Assign all nodes and a start node to `NodeMapNavigator`, then assign Navigator, Canvas, EventSystem, and Loot Label to `NodeMapPresenter`. Each node's `EncounterDefinition` chooses its destination scene and optional loot pool. The old asset-based node map and its wizard have been removed.

Use **Window > RPG Toolkit > Create Demo Content** to create the arena and free-movement demo scenes and assets. The included `Demo/RpgMapDemo` scene has scene nodes and links configured, with reachable nodes using `DemoEncounter`. Open it for map and arena flow, `Demo/RpgFreeDemo` for click-to-move obstacle routing, or `Demo/RpgArenaDemo` to play the arena directly. In the arena, green cells are reachable, the hovered path is amber, and clicking a cell requests movement. Each completed combat tile step advances logical time and raises `CombatTimeline.GridStepResolved` for custom scripts. The demo character has four image attack buttons, including physical and magical examples; each attack asset can supply its own icon. Select an attack, aim with the mouse relative to the actor, inspect the red target tiles, then click the arena to fire. The cursor direction uses 45-degree boundaries between the four cardinal directions. You can move before or after your one attack while movement budget remains; after attacking, exhausting that budget ends the activation. Red health bars update immediately and yellow damage bars follow after a delay. The demo enemy has 30 HP, so moving beside it and using `DemoAttack` demonstrates a quick victory. Wait and Quick Item end the turn at different timeline costs. Winning returns to the map and rolls the encounter loot once into `RunLootLedger`; Retreat returns without rewards. **Window > RPG Toolkit > Run Smoke Checks** checks weighted paths, occupancy, map links, timing, loot, health, and pattern rotation.

## Package contents

When exporting to another Unity project, include:

- `Assets/RpgToolkit` with its `.meta` files and referenced sprites, tiles, scenes, and presets.
- `Assets/Scripts/Grid/GridCoordinate.cs` and `GridLayout.cs` with their `.meta` files. These are the existing shared square-coordinate helpers used by this toolkit. The road placement scripts are not required.
- `Assets/Settings/InputSystem_Actions.inputactions` with its `.meta` file if exporting the demo preset or demo prefabs. A new preset may use another Input Actions asset with a `Player/Move` action and, for point-and-click, a `UI/Click` action.

The destination project needs Unity 6000.6, Input System, Tilemap, and Unity UI packages. Add the demo scenes to Build Settings when importing the demo; `Create Demo Content` also registers them. Event and Rest encounters currently grant their configured loot and return to map selection. Full event/rest interactions, party, inventory UI, equipment, spells, and other movement templates are reserved for later slices.
